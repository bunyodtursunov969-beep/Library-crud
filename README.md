# Library-crud

Library management web application with CRUD operations.

## Tech stack
- Java, Spring MVC
- PostgreSQL, JdbcTemplate
- Thymeleaf, Maven
- Tomcat 10

## Features
- User registration and login
- Create, view, update and delete books
- Multi-language support (uz, ru, en) - in progress

## How to run
1. Create a PostgreSQL database
2. Set your username and password in application.properties
3. Run the project on Tomcat
